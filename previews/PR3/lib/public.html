EpiNow2.EpiNow2 Module
julia
EpiNow2

Estimate real-time case counts and time-varying epidemiological parameters.

A Julia implementation of the EpiNow2 methodology, providing an opinionated, batteries-included interface for Rt estimation using Turing.jl for inference.

Quick start

@example
using EpiNow2
result = epinow(
    example_confirmed()[1:30, :];
    generation_time = gt_opts(example_generation_time()),
    delays = delay_opts(
        discretise(example_incubation_period() + example_reporting_delay())
    ),
    inference = inference_opts(samples = 50, warmup = 50, chains = 1, progress = false),
    verbose = false
)
summary(result)

ADTypes.AutoReverseDiff Type
julia
AutoReverseDiff{compile}

Struct used to select the ReverseDiff.jl backend for automatic differentiation.

Defined by ADTypes.jl.

Constructors

julia
AutoReverseDiff(; compile::Union{Val, Bool} = Val(false))

Fields

  • compile::Union{Val, Bool}: whether to allow pre-recording and reusing a tape (which speeds up the differentiation process).

    • If compile=false or compile=Val(false), a new tape must be recorded at every call to the differentiation operator.

    • If compile=true or compile=Val(true), a tape can be pre-recorded on an example input and then reused at every differentiation call.

    The boolean version of this keyword argument is taken as the type parameter.

Warning

Pre-recording a tape only captures the path taken by the differentiated function when executed on the example input. If said function has value-dependent branching behavior, reusing pre-recorded tapes can lead to incorrect results. In such situations, you should keep the default setting compile=Val(false). For more details, please refer to ReverseDiff's AbstractTape API documentation.

Info

Despite what its name may suggest, the compile setting does not prescribe whether or not the tape is compiled with ReverseDiff.compile after being recorded. This is left as a private implementation detail.

EpiNow2.R_to_growth Function
julia
R_to_growth(R, gt_pmf; newton_steps = 2)

Convert a reproduction number to an exponential growth rate by solving M(-r) = 1 / R, where M is the moment generating function of the generation time. The inverse of growth_to_R.

A fixed number of Newton steps from a small-growth-rate approximation keeps the calculation differentiable with automatic differentiation.

Arguments

  • R: the reproduction number.

  • gt_pmf: generation time probability mass function, with gt_pmf[i] the probability of a generation time of i days.

Keyword Arguments

  • newton_steps: number of Newton steps (default 2).
@example
using EpiNow2
R_to_growth(1.5, [0.2, 0.5, 0.3])

julia
bootstrapped_dist_fit(data; family = :lognormal, max_delay = 30,

Fit a delay distribution by maximum likelihood on bootstrap resamples of the data, to quantify the uncertainty in its parameters.

  • data: a DataFrame with either a :delay column or :date_onset and :date_report columns. Only delays above 0 and up to max_delay are used.

EpiNow2.discretise Function
julia
discretise(d::Distribution; max = nothing, cdf_cutoff = 0.001) -> NonParametricDist

Discretise a continuous distribution into a probability mass function using double interval censoring (matching R's discretise()). The result is a NonParametricDist, which supports + for convolution.

The PMF is 0-indexed: pmf[1] = P(delay = 0), pmf[2] = P(delay = 1), etc.

Arguments

  • d: the delay distribution to discretise.

Keyword Arguments

  • cdf_cutoff: tail probability dropped when max is not given (default 0.001).

using EpiNow2, Distributions

EpiNow2.epinow Function
julia
epinow(data; generation_time, delays, truncation, rt, backcalc, gp, obs,
       forecast, inference, CrIs, target_folder = nothing,
       target_date = nothing, verbose)

Estimate infections, the time-varying reproduction number and the growth rate, and forecast reported cases. A wrapper around estimate_infections that can also save the results.

Arguments

  • data: a DataFrame with :date and :confirm columns, as for estimate_infections.

Keyword Arguments

  • generation_time, delays, truncation, rt, backcalc, gp, obs, forecast, inference, CrIs, verbose: as for estimate_infections.

  • target_folder: directory in which to save the summaries of infections, reports, Rt and growth rate as CSV files; nothing (default) saves nothing.

  • target_date: the Date the forecast horizon counts from. When it lies after the last date in data, the horizon is extended so the forecast still reaches forecast.horizon days beyond it, as in R. nothing (default) counts from the last date in data.

Returns

An EpinowResult whose estimates field holds the EstimateInfectionsResult.

@example
using EpiNow2
result = epinow(
    example_confirmed()[1:30, :];
    generation_time = gt_opts(example_generation_time()),
    delays = delay_opts(example_reporting_delay()),
    inference = inference_opts(samples = 50, warmup = 50, chains = 1, progress = false),
    verbose = false
)
summary(result)

EpiNow2.estimate_dist Function
julia
estimate_dist(data; dist = :lognormal, priors = nothing, primary = :uniform,
              primary_params = Float64[], obs_time_threshold = 2.0,
              inference = inference_opts(), verbose = false)

Estimate a delay distribution from censored and possibly right-truncated delay data by MCMC, accounting for the interval censoring of both the primary and the secondary event. Mirrors EpiNow2's estimate_dist().

Arguments

  • data: a DataFrame in one of two formats. The R format has date columns pdate_lwr (and optionally pdate_upr) for the primary event, sdate_lwr (and optionally sdate_upr) for the secondary event, and optionally obs_date (date of observation) and n (count). The simple format has a single :delay column of non-negative integer delays, with daily censoring windows and no truncation.

Keyword Arguments

  • dist: the distribution family, :lognormal (default) or :gamma.

  • priors: priors on the distribution parameters, as a vector in the order the constructor takes them (e.g. [meanlog_prior, sdlog_prior] for a lognormal); nothing (default) uses built-in priors.

  • primary: distribution of the primary event within its window, :uniform (default) or :expgrowth (exponential growth).

  • primary_params: the growth rate, as a one-element vector, when primary = :expgrowth.

  • obs_time_threshold: observations whose observation time exceeds obs_time_threshold times the maximum delay are treated as not truncated, following the epidist convention (default 2).

  • inference: inference options from inference_opts.

  • verbose: print progress messages (default false).

Returns

An EstimateDistResult whose fitted field is an UncertainDistribution with normal priors from the posterior mean and standard deviation of each parameter, ready for delay_opts, gt_opts or trunc_opts. Its chain field holds the posterior samples.

@example
using EpiNow2, DataFrames, Distributions
data = DataFrame(delay = round.(Int, rand(LogNormal(1.5, 0.5), 100)))
fit = estimate_dist(
    data;
    inference = inference_opts(samples = 50, warmup = 50, chains = 1, progress = false)
)
fit.fitted

EpiNow2.estimate_infections Function
julia
estimate_infections(data; generation_time, delays, truncation, rt,
                    backcalc, gp, obs, forecast, inference, CrIs,
                    verbose)

Estimate infections, the time-varying reproduction number and the growth rate from reported cases, using a renewal equation (or back-calculation) with delays from infection to report, an observation model and an approximate Gaussian process prior.

Arguments

  • data: a DataFrame with :date and :confirm columns. Optional columns are :accumulate (see fill_missing) and :breakpoints (see add_breakpoints).

Keyword Arguments

  • generation_time: generation time options from gt_opts.

  • delays: delays from infection to report, from delay_opts.

  • truncation: right truncation of recent data, from trunc_opts.

  • rt: reproduction number options from rt_opts. Use rt_opts(use_rt = false) to back-calculate infections instead.

  • backcalc: back-calculation options from backcalc_opts.

  • gp: Gaussian process options from gp_opts, or nothing to switch the Gaussian process off (for example with a random walk).

  • obs: observation model options from obs_opts.

  • forecast: forecast options from forecast_opts.

  • inference: inference options from inference_opts.

  • CrIs: credible intervals to summarise (default [0.2, 0.5, 0.9]).

  • verbose: print progress messages (default true).

Returns

An EstimateInfectionsResult with posterior summaries by date in its infections, reports, rt and growth_rate fields and the posterior samples in fit. Use summary(result) for the latest estimates and get_samples for the samples.

@example
using EpiNow2
fit = estimate_infections(
    example_confirmed()[1:30, :];
    generation_time = gt_opts(example_generation_time()),
    delays = delay_opts(
        discretise(example_incubation_period() + example_reporting_delay())
    ),
    rt = rt_opts(rw = 7),
    gp = nothing,
    inference = inference_opts(samples = 50, warmup = 50, chains = 1, progress = false),
    verbose = false
)
summary(fit)

EpiNow2.estimate_secondary Function
julia
estimate_secondary(data; secondary, delays, obs, inference, burn_in = 14,
                   CrIs = [0.2, 0.5, 0.9], verbose = true)

Estimate the relationship between a primary and a secondary observation, e.g. cases and deaths or admissions and bed occupancy: the delay between them and the fraction of primary observations that lead to secondary ones.

Arguments

  • data: a DataFrame with :date, :primary and :secondary columns.

EpiNow2.estimate_truncation Function
julia
estimate_truncation(data; truncation, obs = obs_opts(),
                    noise = Normal(0, 1), inference,
                    CrIs = [0.2, 0.5, 0.9], verbose = true)

Estimate a right-truncation distribution from several snapshots of the same data taken at different times. Recent counts are incomplete in earlier snapshots; comparing them with later snapshots gives the delay until counts are complete, as a lognormal distribution.

  • verbose: print progress messages (default true).

    end
    snap

EpiNow2.gp_opts Function
julia
gp_opts(; basis_prop = nothing, boundary_scale = nothing, ls, alpha,
        kernel = matern, matern_order = 1.5, w0 = 1.0)

Approximate Gaussian process options, for the Hilbert space approximation used to smooth Rt (or infections when back-calculating). Pass gp = nothing to the estimation functions to switch the Gaussian process off.

Keyword Arguments

  • basis_prop: proportion of time points to use as basis functions. Lower values are faster but less accurate. The default, nothing, chooses the number of basis functions from the 5% quantile of the lengthscale prior ls, as in R.

  • boundary_scale: boundary factor of the approximation relative to the half-range of the time points. The default, nothing, chooses it from the 95% quantile of ls (and uses 1.5 for the periodic kernel), as in R.

  • alpha: prior on the magnitude, roughly the expected standard deviation of the process. Defaults to a half-normal with standard deviation 0.01.

  • kernel: a GPKernel: matern (default), se or periodic.

  • matern_order: order of the Matérn kernel: 0.5, 1.5 (default) or 2.5.

  • w0: fundamental frequency of the periodic kernel (default 1.0).

Returns

A GPOpts object.

@example

EpiNow2.rt_opts Function
julia
rt_opts(; prior, use_rt = true, rw = 0, future = latest, fixed_from = nothing,
        gp_on = gp_Rt, pop = 0.0, pop_period = pop_forecast,
        pop_floor = 1.0)

Time-varying reproduction number options.

Keyword Arguments

  • prior: prior on the initial reproduction number. Defaults to a lognormal distribution with mean 1 and standard deviation 1.

  • use_rt: should Rt be used to generate infections and hence reported cases (default true)? If false, infections are back-calculated (see backcalc_opts).

  • rw: step size of a random walk on Rt in days; 0 (default) means no random walk, 7 a weekly random walk. The random walk is combined with the Gaussian process unless gp = nothing is passed to the estimation function, as in R.

  • future: how Rt is treated beyond the data, a ForecastMode: latest (default), project or estimate.

  • fixed_from: when future = estimate, the number of days before the end of the data from which Rt is held fixed. nothing (default) uses the seeding time, as R does: the rounded sum of the delay means, but at least the maximum generation time. Ignored for latest and project.

  • gp_on: what the Gaussian process is applied to, a GPTarget: gp_Rt (default) or gp_R0.

  • pop: initial susceptible population size, as a number or a prior distribution. Used to adjust Rt for susceptible depletion; 0 (default) means no adjustment.

  • pop_period: when the population adjustment applies, a PopPeriod: pop_forecast (default) or pop_all.

  • pop_floor: minimum susceptible population used when adjusting for depletion, to keep it numerically stable (default 1.0).

Returns

An RtOpts object.

@example
using EpiNow2
rt_opts(rw = 7)

EpiNow2.secondary_opts Function
julia
secondary_opts(type = incidence; kwargs...)

Secondary observation model options. The secondary observations are modelled as a convolution of primary observations, optionally combined with current primary observations (additively or subtractively) and optionally cumulative.

Arguments

  • type: the type of secondary observation, a SecondaryType. incidence (default) assumes secondary reports equal a convolution of previous primary reports, e.g. deaths from cases. prevalence assumes they are cumulative and equal current primary reports minus a convolution of secondary reports, e.g. hospital bed use from admissions.

Keyword Arguments

Override the flags set by type:

  • cumulative: should the secondary report be cumulative?

  • historic: should a convolution of primary reports be used to predict secondary reports?

  • primary_hist_additive: should that convolution be added (true) or subtracted (false)?

  • current: should current primary reports contribute to current secondary reports?

  • primary_current_additive: should current primary reports be added (true) or subtracted (false)?

Returns

A SecondaryOpts object.

@example
using EpiNow2
secondary_opts(prevalence)

EpiNow2.simulate_infections Function
julia
simulate_infections(R_trajectory; generation_time, delays, obs,
                    initial_infections = 100.0, pop = 0.0, seed = nothing)

Simulate infections and reported cases from a given Rt trajectory. Infections follow the renewal equation deterministically; reports are then drawn from the observation model. No inference is done.

Arguments

  • R_trajectory: a DataFrame with :date and :R columns.

Keyword Arguments

  • generation_time: generation time options from gt_opts (default: a lognormal with meanlog 1.6 and sdlog 0.5).

  • delays: delay options from delay_opts (default: no delay).

  • obs: observation model options from obs_opts (default: Poisson). With negbin, the overdispersion phi is fixed at 5.

  • initial_infections: number of infections on the last seeding day (default 100).

  • pop: susceptible population size for depletion; 0 (default) means none.

  • seed: random seed, or nothing (default).

Returns

A DataFrame with :date, :infections and :reports columns.

@example
using EpiNow2, DataFrames, Dates

simulate_infections(
    R;
    generation_time = gt_opts(example_generation_time()),
    delays = delay_opts(example_reporting_delay()),
    seed = 1
)
